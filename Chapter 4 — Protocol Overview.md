# Chapter 4 — Protocol Overview

Open Knowledge Protocol (OKP) is an open protocol for creating, connecting, verifying, storing, and accessing knowledge.

It is designed as shared infrastructure rather than a platform owned by a single organization.

The protocol has four main layers.

## 1. Knowledge Layer

The Knowledge Layer defines how knowledge is represented.

It contains entities, claims, relationships, evidence, sources, and other information that together form the **Open Knowledge Graph**.

For example:

**Albert Einstein → developed → Theory of Relativity**

The claim can then be connected to documents, evidence, dates, people, and related concepts.

## 2. Trust Layer

The Trust Layer helps users and applications evaluate knowledge.

It records information such as:

- where a claim came from,
- who published it,
- what evidence supports it,
- who verified or challenged it,
- and how the claim has changed over time.

The Trust Layer does not decide what is true. It provides the information required to make that judgment.

## 3. Open Graph Chain

The Open Graph Chain is the decentralized database that stores and connects the knowledge graph.

Instead of one organization operating the database, independent nodes participate in storing, replicating, validating, and serving the graph.

The graph therefore does not depend on a single company or server to continue existing.

## 4. Application Layer

Applications interact with the graph through the Open Knowledge Protocol.

These could include search engines, research tools, AI assistants, autonomous agents, educational platforms, or entirely new applications built on shared knowledge.

An AI agent, for example, could retrieve a claim together with its evidence, conflicting claims, and provenance before generating an answer.

## Governed as Public Infrastructure

The protocol itself is governed by the **OKP DAO**.

The DAO can govern protocol standards, upgrades, network rules, and shared resources. However, it does not control the knowledge stored in the graph or decide which claims are true.

This separation is important:

**The Open Graph Chain stores the graph.  
The Open Knowledge Protocol defines how knowledge works.  
The OKP DAO governs the protocol.  
No single organization owns the knowledge.**
